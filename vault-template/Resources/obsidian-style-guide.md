## Obsidian Formatting Rules

Apply these when creating or editing vault files.

1. Use `[[wikilinks]]` for every project, person, and note reference. Weave into sentences, not footnotes.
2. Every note gets YAML frontmatter: `type`, `date`, `status`, `tags`, `project` (when applicable).
3. Use Obsidian callouts for structure: `important` for decisions, `todo` for action items, `tip` for wins, `warning` for blockers.
4. Notes should be standalone and composable. No orphan notes — link from at least one existing note.
5. Don't put a `# Title` heading that duplicates the filename.
